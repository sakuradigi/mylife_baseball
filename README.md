## 🌟 遊戲核心特色 (Game Features)

1. **🎓 大學升學路徑 (College Pathway - Age 18~21)**
   - 高三畢業不再只有直接選秀，可選擇升學「大專棒球聯賽 (TW) / 全日本大學選手權 (JP)」，經歷 4 年大學聯賽培養體能與打擊經驗，22 歲以強棒之姿再戰選秀！

2. **🎴 3D 立體質感互動抉擇卡片 (3D Choice Cards)**
   - 全面修復 Image 4 畫面中選項像普通內文的問題。採用獨立半透明玻璃面板、金黃 hover 高亮邊框與按鈕壓下 3D 反饋。

3. **⚾ 真實區分「高中/大學盃賽」與「職業聯賽」數據邏輯**
   - **高中賽事 (HS1~HS3)**：6~14 場淘汰盃賽數據（淘汰制、打席 25~55 次）。
   - **大學賽事 (UNI1~UNI4)**：14~22 場大專聯賽數據。
   - **職業賽事 (PRO)**：120~130 場例行長聯賽數據與完整 Box Score。

4. **⚡ 每個賽季 100% 保障觸發球季中事件**
   - 每個賽季過場 100% 自動發動 1 個球季中事件（包含球隊震撼交易、戀愛/女友/結婚、媒體獨家專訪、宿敵投手正面對決、特製數據分析特訓）。

5. **🏟️ 微妙隱晦真實球隊命名 (Homage Team Naming)**
   - **CPBL 台灣職棒 (6隊)**：`台中象勇` (中信兄弟)、`府城飛獅` (統一7-ELEVEn獅)、`桃園狂猿` (樂天桃猿)、`味全赤龍` (味全龍)、`新北悍將` (富邦悍將)、`高雄鋼鷹` (台鋼雄鷹)。
   - **NPB 日本職棒 (12隊)**：`東京巨人`、`關西猛虎`、`濱海星光`、`廣島赤鯉`、`神宮疾燕`、`名古屋青龍`、`福岡金鷹`、`千葉海鷗`、`關西狂牛`、`東北鷲王`、`西武雄獅`、`北海鬥士`。
