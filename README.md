## 🌟 遊戲核心特色 (Game Features)

1. **🃏 100% 復刻 Image 7/8 互動式 3 應對選項事件卡 (Risk/Reward Choice Cards)**
   - 點擊「抽事件卡」按鈕觸發專屬應對介面！提供 3 種風險與報酬決策按鈕：
     - 🔥 **全力一搏**：`成功率 35% | 加成/減益幅度最大 (±3)`
     - ⚖️ **照常執行**：`成功率 50% | 標準幅度 (±2)`
     - 🛡️ **保守應對**：`成功率 70% | 加成/減益幅度最小 (±1)`
   - 根據抉擇與 PRNG 計算判定，輸出成功或豪賭失敗結果，讓事件充滿強烈參與感！

2. **🪜 完整多階小聯盟與二軍/三軍梯隊升降體驗 (Minor League Ladder)**
   - **美職 6 階梯隊**：`Rook (新人聯盟)` ➔ `1A (低階1A)` ➔ `A+ (高階1A)` ➔ `2A (雙A)` ➔ `3A (三A)` ➔ `MLB (大聯盟一軍)`
   - **日職 3 階梯隊**：`育成三軍` ➔ `日職二軍` ➔ `日職一軍`
   - **中職 2 階梯隊**：`中職二軍` ➔ `中職一軍`
   - 每季結算根據評分 (OVR) 與 WAR 自動進行**升降級評估**，感受從新人聯盟一步一步殺上大聯盟一軍的極致成就感！

3. **🏟️ 30 支美職大聯盟 (MLB) 名門版圖**
   - 包含美聯與國聯共 30 支微妙隱晦名門球隊（如：紐約帝國、波士頓赤襪、洛城湛藍、聖地牙哥修士、舊金山巨龍等）。

4. **🎓 大學升學路徑 (18~21 歲)**
   - 經歷 4 年大學聯賽（大專聯賽 / 全日本大學選手權）培養體能與打擊經驗，22 歲再戰選秀！
