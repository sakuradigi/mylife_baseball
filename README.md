🎮 **[點此立即線上線上試玩遊戲 (GitHub Pages)](https://sakuradigi.github.io/mylife_baseball/)**

## 🌟 遊戲核心特色 (Game Features)

1. **🎲 正宗先擲骰 ➔ 再分配點數 (Roll-First-Then-Assign Dice Engine)**
   - 春訓階段擲出 2~8 顆訓練骰子，點擊骰子卡牌再點選目標屬性膠囊長條圖（體力、Contact/打擊、力量、速度、選球、守備範圍、臂力）。
   - 包含一鍵 `↩ 復原` 配點功能與隱藏異變覺醒（4個6、8個1逆境狂獅、大順子等）。

2. **🌱 4.2 億種子碼 Mulberry32 PRNG 系統**
   - 支持輸入固定種子碼，100% 可重現所有隨機事件、春訓擲骰與生涯發展。

3. **🏆 80 種成就與專屬稱號數據庫**
   - 包含單季 40 轟/打擊王/勝投王、千安百勝名人堂、億萬年薪與隱藏彩蛋稱號。

4. **🎒 常駐裝備、豪宅跑車與傳承機制**
   - 退役時可選擇一件常駐型裝備轉贈給下一次創角的球員，帶領前輩的棒球魂繼續奮戰！

5. **👔 退役開啟職棒總教練模式 (Manager Mode)**
   - 引退後受邀擔任一軍總教練，帶領年輕球員爭奪總冠軍！

## 🚀 快速開始 (Quick Start)

只需要瀏覽器即可直接遊玩，無需安裝任何套件：

```bash
git clone https://github.com/sakuradigi/mylife_baseball.git
cd mylife_baseball
# 使用任何 Web Server 開啟 index.html (例如 python3 -m http.server 8000)
```
