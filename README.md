## 🌟 遊戲核心特色 (Game Features)

1. **🎨 墨綠極簡視覺 (3-5 專屬配色對齊)**
   - 採用與《yakyulife》原版一致的墨綠質感配色（`#091512` 深墨綠、`#2a9d8f` 翡翠綠、`#f4a261` 暖金），風格統一純淨，絕不花哨雜亂。

2. **📊 100% 復刻 Image 3 正宗賽季結算面板 (Season Box Settlement)**
   - 呈現完整季末報告：`◆ 體力與健康回報` (受傷機率)、`◆ 球季數據 (出賽/打席/AVG/OBP/SLG/OPS/安打/全壘打/打點/保送/盜壘/守備)`、`◆ 季末結算` (年薪與合約剩餘年限)、`◆ 升降級通知` 與 `◆ 球隊戰績 (勝敗排名與總冠軍)`。

3. **💍 球季中事件引擎 (In-Season Events)**
   - **交易事件 (Trades)**：隨機觸發球團交易被派往全新強權發揮。
   - **戀愛與結婚 (Romance & Marriage)**：結識體育女主播、青梅竹馬或當紅偶像，交往並舉辦世紀婚禮解鎖「愛妻家」稱號！
   - **自由球員 (FA) 與合約談判**：複數年合約到期後重新簽署高薪合約。

4. **📊 逐年生涯完整數據總表 (Career Stats Table)**
   - 於「榮譽與生涯數據」分頁提供完整的生涯歷史表格，紀錄每年的年齡、效力球隊、層級、打擊率/防禦率、OPS/WHIP、WAR、球隊戰績與冠軍榮譽。

5. **👴 30歲後能力衰退與引退抉擇 (Decline & Voluntary Retirement)**
   - 30 歲後自然體能衰退，考驗老將經驗；34 歲後每季跳出引退對話框，由玩家自主決定何時脫下戰袍。

6. **🎲 正宗先擲骰 ➔ 再分配點數 (Roll-First-Then-Assign Dice Engine)**
   - 春訓階段擲出 2~8 顆訓練骰子，點擊骰子卡牌再點選目標屬性膠囊長條圖。包含一鍵 `↩ 復原` 配點功能與隱藏異變覺醒。
